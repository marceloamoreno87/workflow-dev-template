# Route Codex models by task

The Harness explicitly selects both model and reasoning effort for every Agent Role: GPT-5.6 Luna handles narrow high-volume mechanical work, Terra handles routine exploration, specification, implementation, testing, and standard review, and Sol handles architecture, security, critical review, ambiguity, and escalations. Routing changes require representative evals measuring correctness, regressions, intervention, duration, tokens, and end-to-end cost rather than relying on per-token price alone.
