# Compose ephemeral Agent Roles

Product, Architect, Backend, Frontend, QA, Security, DevOps, and Reviewer are ephemeral roles selected by the Spec and risk profile rather than a mandatory fixed pipeline. Independent branches may run concurrently, privileged effects cross Capability Brokers, and Reviewer never shares the implementer's session. The orchestrator records each handoff as structured evidence instead of relying on conversational continuity.
