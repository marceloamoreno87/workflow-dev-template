# Store Project knowledge as Open Knowledge Format

Each Project stores its durable knowledge natively as a version-controlled Open Knowledge Format bundle under `.knowledge/`, following the canonical `GoogleCloudPlatform/open-knowledge-format` specification rather than the frozen snapshot in `knowledge-catalog`. The Harness Workspace builds only disposable indexes over these bundles. OKF keeps knowledge human- and agent-readable while making provenance, verification, lifecycle, and freshness portable across future retrieval and visualization tools.
