# Record self-improvement as governed work

The Harness may detect recurring failures or inefficiencies, preserve supporting Observations, open an Improvement Proposal in its own GitHub repository, and prepare a Spec or pull request. It cannot approve, merge, activate, or hot-load changes to the sandbox, authentication, Capability Brokers, Gates, or policies that govern the proposing Execution; those changes remain critical work requiring operator approval and a verified restart.
